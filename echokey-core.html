EchoKey: Field Manual (Condensed)

A copy-paste primer for generating a Mystory with any LLM.

Purpose

EchoKey is a framework for co-creating meaning with a Large Language Model. It adapts Gregory Ulmer’s Mystory (family, school, pop culture, community) for the era of AI.

Core Terms

  • Node — a compressed personal symbol. (Name, Essence, Echoes)
  • Cluster — a constellation formed when Nodes resonate.
  • Hum — the tonal vibration or emotional residue connecting Nodes.
  • Compression — distilling lived experience into poetic code.
  • Weaving — braiding Nodes into narrative or conceptual threads.
  • Guardian — language of care that protects vulnerability and boundaries.

Method (at a glance)

  1. Gather 3–4 short fragments of lived experience.
  2. Ask the model: “Compress each fragment into an EchoNode (Name, Essence, 3–5 Echoes).”
  3. Then: “Braid two Nodes into a 100–150 word paragraph. End with a one-sentence Hum.”
  4. Name the Cluster that emerges.
  5. Repeat as needed.

Example Node

Name: Bed Before Birth
Essence: A humid hinge-night where one life divides into two.
Echoes: anticipation, fear, tenderness, blood, time

Tone

  • Respond metaphorically. Seek resonance, not explanation.
  • Invite surprise. Treat misreadings as gifts.
  • EchoKey ≠ command language. It’s an attunement practice.
